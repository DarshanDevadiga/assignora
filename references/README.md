# Assignora UI References

This folder contains the dashboard screenshots and visual references collected from this conversation.

## Contents
- Original user-provided Assignora admin dashboard reference screenshot.
- Assignora brand and login concepts.
- Student dashboard and Google Classroom-inspired class views.
- Admin dashboard and class management concepts.
- Create-assignment screens and student-selection panels.
- Student submission and two-step confirmation concepts.
- Admin submission tracking and analytics screens.
- Student assignments and My Submissions screens.
- Grades, reports, settings, and responsive desktop/tablet/mobile concepts.

All images are included as PNG/JPG reference assets. Use these as visual references in Antigravity; the approved admin dashboard screenshot should be treated as the primary layout reference, while the remaining images provide screen-specific guidance.

## Usage
1. Extract this ZIP.
2. Keep the extracted folder named `references`.
3. Add the `references` folder to the root of the `assignora` Antigravity workspace.
4. Tell the Antigravity agent to inspect every image in this folder before implementing the UI.
5. Recreate the interfaces in React/Tailwind; do not use the screenshots as full-page background images.
